# Boba Battle · เกมทวนสอบวัดประเมิน

เกมต่อสู้ผลัดตากับบอท แบบเดียวกับ Power Battle (`chula/ปี 3 เทอม 1/นวัตกรรม/งาน AI เกม AR/เว็บ ar`) แต่ตัดโหมด AR ออกแล้ว
คำถาม 100 ข้อมาจาก "สรุปวัดประเมิน.pdf" หน้า 8–22

## เปิดเกม
ดับเบิลคลิก `เปิดเกม.command` (ถ้า macOS ถาม ให้คลิกขวา > Open)
ห้ามเปิด `index.html` ด้วยการดับเบิลคลิกตรงๆ เพราะเพลง YouTube จะเล่นไม่ได้

## เปลี่ยนรูปอาวุธ/บัฟ
วางไฟล์ PNG (พื้นหลังโปร่งใส) ในโฟลเดอร์ `img/` ตามชื่อนี้ แล้วรีเฟรชหน้าเกม ถ้ายังไม่มีไฟล์ เกมจะใช้อีโมจิแทน

| ของ | ชื่อไฟล์ |
|---|---|
| 🗡️ ดาบ | `img/sword.png` |
| 🏹 ธนู | `img/bow.png` |
| 🪄 คทาเวท | `img/staff.png` |
| 💥 ดาบระเบิดพิษ | `img/katana.png` (ใส่แล้ว) |
| 🛡️ โล่ | `img/shield.png` |
| 🪞 สะท้อน | `img/reflect.png` |
| 💚 ฮีล | `img/heal.png` |
| ✨ ล้างสถานะ | `img/cleanse.png` |

## แก้คำถาม
แก้ใน `questions.js` (ตัวเลือกแรก `o[0]` คือคำตอบที่ถูก) แล้วรัน
- `node check.js` ตรวจจำนวนข้อ สัดส่วน และคำนวณคำตอบข้อคำนวณซ้ำ
- `node make-pdf.js` สร้าง PDF เฉลยใหม่ (`../เฉลย_แบบทดสอบ100ข้อ_วัดประเมิน.pdf`)

## ไฟล์
- `index.html` หน้าเกม เสียงเอฟเฟกต์ และเพลง YouTube
- `logic.js` กติกาการต่อสู้ (ยกมาจาก Power Battle)
- `questions.js` คำถาม 100 ข้อ และคำอธิบายเฉลย
- `img/player.png`, `img/bot.png` ตัวละครที่ตัดพื้นหลังแล้ว
